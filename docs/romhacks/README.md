- [Playing a romhack](PLAYING.md): generating a romhack from your ROM, switching back to the base game.
- [Romhacks design](DESIGN.md): how romhack support works and how to port a new hack.
- [Level and behavior scripts](SCRIPTS.md): the scripts romhacks and mods load from their archives.
